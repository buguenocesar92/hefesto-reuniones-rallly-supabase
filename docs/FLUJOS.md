# Flujos de demostración
Crear estas votaciones manualmente en un espacio de prueba; no hay seed ni publicación automática.

## 1. Inicio de proyecto con un cliente
Título: Kickoff — Proyecto DEMO.
Proponer tres opciones en días distintos y una duración concreta. Indicar agenda breve, responsable y fecha límite para responder. Compartir únicamente el enlace de participación, no una URL de administración o sesión. Desde un segundo navegador marcar disponibilidad y revisar qué datos de otros participantes se muestran.

## 2. Taller de capacitación
Proponer fechas considerando la zona America/Santiago. Probar desde un navegador configurado en otra zona y confirmar que el instante es el mismo aunque cambie la hora local. Revisar la zona indicada al destinatario, especialmente cerca de cambios de horario de verano. No publicar datos sensibles en título/descripción.

## 3. Revisión de entrega
Definir dos o tres bloques concretos, recoger disponibilidad y cerrar la votación después de confirmar el horario con las personas. El voto no equivale por sí solo a una reunión aceptada ni reserva una sala/recurso en otro sistema.

Para cada flujo: crear → copiar enlace de participación → responder desde otro perfil → modificar una respuesta propia → revisar permiso de visitante → cerrar/confirmar opción disponible en la edición → enviar confirmación por el medio acordado. La disponibilidad exacta de funciones avanzadas depende de la edición/licencia instalada; no se desbloquean en este kit.

Antes de usar el proceso: elegir idioma de la interfaz y comprobar textos, fechas y zonas reales. Mantener política de acceso, retención y retirada de votaciones acordada. Una allowlist de cuentas no convierte automáticamente todos los enlaces de participación en confidenciales.
