# Integraciones y oferta de Hefesto
Odoo: registrar la URL de la votación en la oportunidad/proyecto correspondiente y, cuando se confirme una hora, crear la actividad/reunión en Odoo mediante su interfaz. No copiar enlaces administrativos o códigos de sesión a un CRM compartido. No hay conector ni evento Odoo creado por este ZIP.

WordPress: usar un botón con la URL de participación exacta de la votación publicada. Revisar permisos antes de enlazarla desde una página pública. No se instala un plugin ni un iframe que el producto no haya habilitado para ese uso.

Calendario: confirmar la fecha/hora con los asistentes y trasladarla por el método nativo disponible en su edición o manualmente. Probar zona y cambios horarios; una votación no reserva automáticamente recursos. No hay OAuth de Google/Microsoft ni acceso al calendario personal de César en esta entrega.

n8n/automatización: una integración futura requiere una API o mecanismo documentado de la versión concreta, autenticación y control de duplicados. No fabricar un CRUD modificando tablas Prisma directamente para simular una API.

Oferta: puesta en marcha, correo/acceso, capacitación, soporte y actualización. Revisar LICENSE-Rallly.txt y condiciones de las funciones licenciadas; mantener atribución y no prometer marca blanca, pagos o funciones Pro solo por desplegar la imagen.
